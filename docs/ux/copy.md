# Тексты интерфейса

Тон: спокойный и конкретный, на «ты» к студентке в подсказках только там, где уже принято в приложении; без обвинений («Вы отстаёте» запрещено).

| Где | Текст |
|---|---|
| Предметы, заголовок | Предметы |
| Переключатель | Ближайшие · Все · Прошедшие |
| Срок | через N дней · сегодня · прошёл |
| Прогресс | 18 из 40 билетов · 23 без ответа |
| Кнопка предмета | Продолжить · Подготовить · Добавить билеты |
| Новый предмет | + Новый предмет |
| Мастер | Шаг 2 из 3 · Назад · Дальше: список билетов |
| Зона загрузки | Перетащите файлы сюда · PDF, DOCX, TXT, MD · можно сразу много |
| Статусы источника | Загружен · В очереди · Читаю… 45% · Прочитан · Отключён · Не удалось прочитать · Попробовать снова |
| Список билетов, пусто | Билетов пока нет. Вставьте список вопросов или загрузите файл |
| Глубина | Кратко · Стандарт · Подробно |
| Пожелания (placeholder) | Например: как у Иванова, с классификацией и схемой |
| Кнопки ответа | Составить ответ · Составить заново · Дополнить · Зафиксировать |
| Панель покрытия | Нашла в материалах · сильно · слабо · Использовать · Выбрать источники |
| Нет источников | По этому вопросу в материалах ничего не нашла. Загрузите ещё источники или составьте ответ по минимуму |
| Блок пробелов | Не найдено в материалах |
| Повторение | Показать ответ · Ещё раз · Знаю · Осталось 6 |
| Чат | Ищу по всем предметам |
| Телефон | Это удобнее сделать на ноутбуке |
| Ошибки | Причина + что делать: «Три страницы не прочитались. Загрузите файл в другом формате» |
