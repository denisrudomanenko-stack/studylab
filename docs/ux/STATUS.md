# STATUS · StudyLab UX-проект

Живой документ. Источник правды о том, что сделано, что на ревью и что решено. Обновляет дизайнер-ревьюер после каждого ревью. Новая сессия или новый агент начинает отсюда.

**Обновлено:** 16 октября 2026.

## Роли и процесс
- **Владелец (Денис)** ничего не делает руками: пересылает сообщения между дизайнером и Кодом, присылает материалы, решает по бюджету и зависимостям.
- **Дизайнер-ревьюер (Claude в чате)**: проектирование, задания, входные материалы, ревью PR (задачи 03, 04, 06, 10, 11 и 12 — обязательно мои; остальные Код вливает сам).
- **Код (Claude Code)**: вся реализация. Одна задача — одна ветка `feat/ux-NN-…` — один PR. Не вливать PR, ждущий ревью, без слова «принято».
- Деплой на сервер выполняет владелец. `gh pr create` не работает, PR открываем через `gh api`.
- Главный приоритет продукта: путь «источники → идеальный конспект ответа на билет» (только из материалов Томы, источник у каждого тезиса, иллюстрации, глубина задаётся студенткой). Проверка ответа студента и напоминания лежат в бэклоге.

## Журнал решений владельца
- Устройства: ноутбук и планшет; на телефоне Тома работает только с готовыми билетами и с ассистентом.
- Масштаб: более 10 предметов, 30–50 билетов в каждом (может быть больше). Даты экзаменов известны заранее.
- Семестр — полгода обучения, половина курса. Тома сейчас на 3 семестре, 2 курс.
- Ответы на билеты готовятся **только вручную** по отмеченным пунктам списка, не автоматически. Список ведётся вручную, вставкой или импортом из файла.
- Форматы импорта списка: TXT, DOCX, PDF, JPG, PNG, фото с iPhone. XLSX и HEIC пока отдают понятную ошибку.
- Зависимости `openpyxl` (XLSX) и `pillow-heif` (HEIC) **не согласованы**. Pillow не добавляем, изображения через PyMuPDF.
- Иллюстрации обязательны в ответах на билеты и нужны ассистенту; описание картинок включено по умолчанию.
- Лимиты и бюджет модели Timeweb владелец снял («пусть тебя не беспокоят»).
- Напоминания желательны, но в поздней версии. Материалы загружает Тома, владелец только на этапе тестирования.
- Реальных файлов со списками билетов пока нет, Код тестирует на фикстурах из `docs/ux/fixtures/`.

- 2–3 реальных файла со списками билетов, включая фото с iPhone (от владельца).
- Решение по `openpyxl` и `pillow-heif`.
- Задеплоен ли PR #6 и последующие.
