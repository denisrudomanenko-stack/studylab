# Запуск разработки: готовые промпты для Claude Code

Работать строго по порядку: 01 → 02 → 03 → 04 → 05. Каждая задача — отдельная сессия и отдельный PR. Следующую начинать после слияния предыдущей.

## Общий префикс (вставлять первым в каждую сессию)
```
Ты реализуешь задания дизайнера для StudyLab. Сначала прочитай CLAUDE.md, docs/ux/README.md,
docs/ux/design-system.md, docs/ux/dev-setup.md и docs/ux/pr-checklist.md.
Работай только по указанному заданию, в новой ветке от свежего main (feat/ux-NN-…). Не вливай в main сам:
открой PR по чек-листу. Если задание противоречит коду или неоднозначно, остановись и задай вопрос, не додумывай.
Команды деплоя на сервер не выполняй.
```
