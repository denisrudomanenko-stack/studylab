# 09 · Телефонный режим (P1)

## Принцип
С телефона Тома **только** читает готовые билеты, повторяет и общается с ассистентом. Подготовка (предметы, загрузка, список билетов, генерация, пожелания) — на ноутбуке и планшете.

## Что сделать
- При ширине ≤ 768 px (или `pointer: coarse` + узкий экран): нижняя панель «Билеты · Спросить · Профиль».
- Скрыть: «+ Новый предмет», вкладку «Материалы», зону загрузки, вставку списка, «Составить ответ/заново», пожелания, очередь. Вместо них, где пользователь мог бы их ожидать, короткая подсказка: «Это удобнее сделать на ноутбуке».
- «Билеты»: только готовые, фильтр «Ещё раз»; открытие билета — чтение ответа (глубина переключается, без перегенерации).
- Источник по чипу открывается **нижней шторкой**, не уводя со страницы.
- «Спросить»: чат; список бесед выезжает (уже сделано); подпись «Ищу по всем предметам».
- «Повторение» (задача 07) доступно.

## Критерии приёмки
- На 390×844 нет горизонтальной прокрутки, цели нажатия ≥ 44 px.
- Любое действие «подготовки» недоступно с телефона и не ломает экран.
- Safari iOS: корректные отступы под системные панели (`env(safe-area-inset-*)`).
