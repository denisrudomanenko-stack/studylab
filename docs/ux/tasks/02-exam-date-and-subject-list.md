# 02 · Семестр, дата экзамена и список предметов (P0)

## Зачем
Предметов больше десяти, они относятся к разным семестрам (семестр — половина курса; Тома сейчас на **3-м семестре 2 курса**), даты экзаменов известны. Первое, что нужно Томе: «какие предметы в этом семестре, какой экзамен ближе, сколько я успела».

## Что сделать

### Данные
- `ALTER TABLE subjects ADD COLUMN semester INTEGER DEFAULT 0` — **сквозной номер семестра** обучения (1–12). Курс выводится: `ceil(semester / 2)`. Существующее поле `year` не удалять; при заданном `semester` заполнять `year` автоматически.
- `ALTER TABLE subjects ADD COLUMN exam_date TEXT DEFAULT ''` (`YYYY-MM-DD`, пусто = не задана).
- `POST /api/subjects` принимает `semester` и `exam_date`.
- Новый `PUT /api/subjects/{slug}`: `title`, `semester`, `exam_date`, `description`. Права: любой авторизованный.
- `GET /api/subjects` дополнительно возвращает `semester`, `exam_date`, `ticket_count`, `answered_count` (`status='generated'`). Задача 07 добавит `known_count`.
- «Текущий семестр» пользователя: хранить в `localStorage` (`sl-semester`), по умолчанию — наибольший семестр среди предметов с будущей датой экзамена, иначе наибольший семестр вообще.

### Экран «Предметы» (главный)
- Сверху переключатель семестров: «3 семестр» (текущий) · «2 семестр» · … · «Все семестры». Показывать только семестры, в которых есть предметы.
- Внутри семестра: сортировка по `exam_date` по возрастанию, без даты — в конце; прошедшие экзамены — свёрнутой группой «Прошедшие» внизу.
- Поиск по названию (на клиенте).
- Карточка предмета: название, бейдж «через N дней» (склонения через `plural`; сегодня → «сегодня», раньше → «прошёл»), полоса прогресса `answered_count / ticket_count`, подпись «18 из 40 билетов · 23 без ответа», кнопка «Открыть».
- Кнопка ведёт в **список билетов** предмета. Если билетов нет: «Добавить билеты». Если материалов нет: «Подготовить» (мастер, шаг 2).
- Цвет бейджа срока: ≤ 7 дней — `warn`, ≤ 3 дня — `bad`.
- «+ Новый предмет» — мастер (задача 01); семестр в нём по умолчанию равен выбранному.

## Критерии приёмки
- Предметы выбранного семестра ближайшим экзаменом вверх; прошедшие не мешают.
- Семестр и дату можно задать при создании и изменить («⋯» → «Изменить»).
- Счётчики совпадают с реальным списком билетов.
- 15 предметов читаются без горизонтальной прокрутки на ноутбуке и планшете.

## Вне объёма
Напоминания (бэклог). Прогресс «знаю / ещё раз» — задача 07.
