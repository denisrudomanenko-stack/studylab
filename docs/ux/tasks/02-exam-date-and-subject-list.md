# 02 · Дата экзамена и список предметов (P0)

## Зачем
Предметов больше десяти, даты экзаменов известны. Первое, что нужно Томе: «какой экзамен ближе и сколько я успела».

## Что сделать

### Данные
- `ALTER TABLE subjects ADD COLUMN exam_date TEXT DEFAULT ''` (формат `YYYY-MM-DD`, пусто = не задана).
- `POST /api/subjects` принимает `exam_date`.
- Новый `PUT /api/subjects/{slug}`: можно менять `title`, `year`, `exam_date`, `description`. Права: любой авторизованный (студентка управляет своими предметами).
- `GET /api/subjects` дополнительно возвращает: `exam_date`, `ticket_count`, `answered_count` (билетов с `status='generated'`). Задача 07 добавит `known_count`.

### Экран «Предметы» (главный)
- Сортировка по `exam_date` по возрастанию, предметы без даты в конце, **прошедшие** — в отдельной вкладке.
- Сегментированный переключатель: «Ближайшие» · «Все» · «Прошедшие» (по умолчанию «Ближайшие»: экзамен в будущем или без даты).
- Поиск по названию (фильтрация на клиенте).
- Карточка предмета: название, бейдж «через N дней» (склонение через `plural`; сегодня → «сегодня», вчера и раньше → «прошёл»), полоса прогресса `answered_count / ticket_count`, подпись «18 из 40 билетов · 23 без ответа», кнопка «Продолжить».
- «Продолжить» ведёт в билеты предмета. Если билетов нет: «Добавить билеты». Если материалов нет: красная кнопка «Подготовить» (в мастер на шаг 2).
- Кнопка «+ Новый предмет» ведёт в мастер (задача 01).
- Цвет бейджа срока: ≤ 7 дней — `warn`, ≤ 3 дня — `bad`, иначе нейтральный.

## UI-схема
```
Предметы                         [Поиск…]
[Ближайшие] [Все] [Прошедшие]
┌───────────────────────────────────────┐
│ Микробиология         [через 12 дней] │
│ ▓▓▓▓▓▓▓░░░░░░░░                       │
│ 18 из 40 билетов · 23 без ответа  [Продолжить]
└───────────────────────────────────────┘
```

## Критерии приёмки
- Предметы с ближайшей датой сверху; без даты внизу; прошедшие не мешают.
- Дату можно задать при создании и поменять потом (меню «⋯» карточки → «Изменить дату»).
- Счётчики совпадают с реальным списком билетов.
- Список из 15 предметов читается без прокрутки по горизонтали на ноутбуке и планшете.

## Вне объёма
Напоминания (бэклог). Прогресс по «знаю/ещё раз» — задача 07.
