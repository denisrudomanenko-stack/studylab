# 03 · Вставка списка билетов и список билетов в масштабе (P0)

## Зачем
В предмете 30–50 билетов, иногда больше. Добавлять по одному неприемлемо, а список из 40 строк без поиска и фильтров не обозреть.

## Что сделать

### Вставка списка
- На экране билетов, когда билетов нет, главный блок — большое поле: «Вставьте список вопросов, по одному на строку». Когда билеты есть — кнопка «Вставить список» открывает то же в модальном окне.
- Предпросмотр до сохранения: «Найдено 38 вопросов», первые 3 строки, подсветка подозрительных (слишком короткие < 8 символов, дубликаты).
- Кнопка «Добавить 38 билетов». Использовать существующий `POST …/tickets/batch`.
- Улучшить разбор на сервере (`batch_create_tickets`): кроме «1. », «1) », «- » снимать «Билет 1.», «Вопрос 1:», «№1»; склеивать многострочный вопрос, если следующая строка не начинается с номера (необязательно, если сложно: тогда оставить как есть и описать ограничение); убирать точные дубликаты внутри списка и относительно существующих билетов, возвращать `skipped` с числом пропущенных.
- Хранить **порядковый номер** билета в предмете (`position`), а не показывать `id`: `ALTER TABLE exam_tickets ADD COLUMN position INTEGER DEFAULT 0`, заполнять при создании, для старых — по порядку id.

### Список билетов
- Заголовок: «Знаю … · Ещё раз … · Без ответа …» (пока только «Готово N из M · Без ответа K»; остальное в задаче 07).
- Поиск по тексту вопроса и фильтры-чипы: «Все», «Без ответа», «Готовы».
- Строка: номер, вопрос (до 2 строк), бейдж статуса («Нет ответа» / «Готов»), кнопка «Открыть». Действия «⋯»: «Обновить ответ», «Скачать HTML», «Удалить».
- Развёртывание ответа в строке убрать: открытие билета — отдельный экран (задача 08). До этой задачи допустимо оставить текущее раскрытие.
- Отдельная кнопка «Подготовить ответы на все без ответа» появится в задаче 06; место под неё в шапке списка предусмотреть.

## Критерии приёмки
- Вставка 40 строк с нумерацией разных видов даёт 40 билетов с правильными номерами.
- Повторная вставка того же списка не создаёт дубликатов и сообщает «Пропущено 40 повторов».
- Поиск и фильтры работают на 100+ билетах без задержки.

## Вне объёма
Импорт списка из файла и фото (бэклог P2).
