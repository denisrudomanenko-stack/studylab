# 01 · Права студентки и мастер подготовки предмета (P0)

## Зачем
Тома загружает материалы сама. Сейчас создание предмета, индексация, включение/отключение, переименование и удаление источников доступны только админу, а в интерфейсе эти кнопки показываются только админу. Без этого главный путь невозможен.

## Что сделать

### Права (бэкенд)
- Разрешить роли `student`: создавать предмет (`POST /api/subjects`), индексировать (`…/sources/{src}/index`), включать/отключать (`activate`/`deactivate`), переименовывать, удалять **источник**.
- Удаление **предмета** (если есть или появится) оставить админу.
- Заменить `Depends(admin_user)` на `Depends(current_user)` в перечисленных эндпоинтах. Проверить, нет ли других мест, где права зашиты в интерфейсе (`isAdmin`).
- Смена пароля и действия с пользователями остаются админскими.

### Автоматическая индексация
- После успешной загрузки файла индексация запускается автоматически (в фоне, как сейчас делает `index`), а по завершении источник становится `active`. Ручная кнопка «Индексировать заново» остаётся в меню «⋯».
- Параллелизм ограничить: сервер 2 CPU / 2 ГБ RAM. Не более 1–2 одновременных индексаций, остальные в очереди (статус `queued` или `uploaded` с подписью «в очереди»).
- Ошибка индексации → статус `error`, причина коротко в интерфейсе.

### Статусы на человеческом языке (только интерфейс)
| Технически | Показываем |
|---|---|
| `uploaded` | «Загружен» / «В очереди» |
| `indexing:*` | «Читаю… 45%» (фазы не показывать) |
| `indexed`, `active` | «Прочитан» |
| `inactive` | «Отключён» |
| `error` | «Не удалось прочитать» + причина + «Попробовать снова» |

«Частично прочитан» (часть страниц не распознана) — **вне объёма**: если из конвертации легко получить число пустых/нечитаемых страниц, показать, иначе отложить.

### Мастер «Новый предмет» (3 шага)
Маршрут `#/new` (или модальное окно на всю высоту).
1. **Предмет:** название, **семестр** и **дата экзамена** (поля добавляются в задаче 02; пока 02 не готова, можно оставить заглушки).
2. **Материалы:** зона загрузки (перетаскивание, много файлов сразу), список файлов со статусами и прогрессом. «Дальше» доступно, когда хотя бы один файл прочитан или пользователь явно пропускает шаг.
3. **Билеты:** внести список вручную или загрузить файлом/фото (см. задачу 03). Ответы здесь **не** готовятся: шаг заканчивается сохранением списка. Можно пропустить и вернуться позже.
Верх мастера: «Шаг 2 из 3» и полоса прогресса. Уйти и вернуться можно в любой момент: предмет создаётся на шаге 1, дальше всё сохраняется сразу.

## UI-схема (шаг 2)
```
Новый предмет                      Шаг 2 из 3
[=========>        ]
┌ - - - - - - - - - - - - - - - - - - - ┐
  Перетащите файлы сюда
  PDF, DOCX, TXT, MD · можно сразу много
└ - - - - - - - - - - - - - - - - - - - ┘
 Лекция 4.pdf       [прочитан]
 Учебник.pdf        [читаю… 45%]
 Конспект.docx      [не удалось прочитать · Попробовать снова]
[Назад]                [Дальше: список билетов]
```
Классы: `.drop-zone`, `.badge-*`, `.progress`, `.btn-primary` — уже есть.

## Критерии приёмки
- Пользователь с ролью `student` создаёт предмет, загружает 3 файла разом, видит прогресс и после индексации «Прочитан» без участия админа.
- Студент не видит и не может вызвать админские действия (удаление предмета, пароли).
- Загрузка 5 файлов подряд не роняет сервер: индексация идёт по очереди.
- Все тексты из `copy.md`, обе темы, Safari.

## Вне объёма
Редактирование предмета (дата, название) — задача 02. Список билетов — задача 03.
