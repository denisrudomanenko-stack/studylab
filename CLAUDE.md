# StudyLab — персональная образовательная среда

Веб-приложение для подготовки к экзаменам: загрузка учебных материалов, семантический
поиск, ИИ-ассистент по источникам, генерация ответов на экзаменационные билеты.

## Timeweb Cloud AI API

Чат-ассистент и OCR работают через Timeweb AI API. Ключ уже есть на сервере.

**Эндпоинт:** `https://api.timeweb.cloud/api/v1/cloud-ai/`
**Авторизация:** Bearer-токен (лежит в nginx конфиге ic-tp-graph.conf на сервере).

Извлечь токен:
```bash
grep -oP 'Bearer \K[^"]*' /etc/nginx/sites-enabled/ic-tp-graph.conf | head -1
```

**Модели для StudyLab:**

| Задача | Модель | model_name |
|--------|--------|------------|
| Q&A по источникам | Gemini 3.5 Flash | `gemini/gemini-3.5-flash` |
| Генерация ответов на билеты | Gemini 3.5 Flash (или DeepSeek V4 Pro для качества) | `gemini/gemini-3.5-flash` |
| OCR конспектов (фото) | Gemini 3.5 Flash (Vision) | `gemini/gemini-3.5-flash` |

**Формат запроса (OpenAI-совместимый):**
```python
import httpx

response = httpx.post(
    "https://api.timeweb.cloud/api/v1/cloud-ai/chat/completions",
    headers={"Authorization": f"Bearer {TIMEWEB_API_KEY}"},
    json={
        "model": "gemini/gemini-3.5-flash",
        "messages": [
            {"role": "system", "content": "системный промпт"},
            {"role": "user", "content": "вопрос"}
        ],
        "stream": True,
        "max_tokens": 4096,
        "temperature": 0.3
    },
    timeout=120
)
```

**Стриминг:** SSE, формат `data: {"choices":[{"delta":{"content":"..."}}]}`.

**Vision (для фото конспектов):**

            {"type": "image_url", "image_url": {"url": "data:image/jpeg;base64,..."}}

## mklib — движок индексации

`mklib.py` переиспользуется из проекта mklib. Ключевые функции:
- `convert_source()` — PDF/DOCX → markdown
- `segment_text()` — сегментация текста
- `embed_texts()` / `embed_query()` — эмбеддинги через ollama
- `open_db()` / `init_db()` / `db_upsert()` / `db_search()` — sqlite-vec
- `chunk_segment()` — нарезка на чанки

Эмбеддер: `http://127.0.0.1:11434/v1`, модель `bge-m3` (1024d, мультиязычная),
префиксы по документации bge-m3 (без специальных префиксов для dense retrieval).

## Авторизация

- Логин + пароль, bcrypt-хеш в SQLite
- JWT в httpOnly cookie
- Два пользователя: admin (Денис), student (Тома)
- Пароли задаются через .env (ADMIN_PASSWORD, STUDENT_PASSWORD)
- Новых пользователей создаёт только админ
- **Требования к паролю:** минимум 8 символов, минимум 1 заглавная буква, минимум 1 спецсимвол
- **Смена/сброс пароля (Тома):**
  1. Тома нажимает «Забыла пароль» или «Сменить пароль»
  2. На y53@yandex.ru (админ) приходит письмо со ссылкой подтверждения
  3. Пока запрос активен, кнопка создания нового запроса заблокирована
  4. Админ кликает ссылку → Тома получает ссылку на установку нового пароля
- **SMTP:** Яндекс (smtp.yandex.ru:465, SSL), от y53@yandex.ru
- `.env`: SMTP_EMAIL, SMTP_PASSWORD, SMTP_HOST, SMTP_PORT

## Чат-ассистент: история бесед

- Каждая сессия с ассистентом — отдельная **беседа** (conversation)
- Автозаголовок из первого вопроса (можно переименовать)
- Боковая панель: список бесед с поиском по тексту сообщений, сортировка по дате
- Удаление отдельных бесед или пакетно
- Без ветвления — только независимые беседы

## ИИ-ассистент (RAG)

1. Вопрос → embed_query (ollama, bge-m3) → вектор 1024d
2. Поиск в sqlite-vec: чат по всем предметам, билеты только по своему (only_subject)
3. Dual threshold: max_score < 0.40 → «не найдено», 0.40-0.50 → weak_relevance warning
4. Системный промпт + фрагменты → DeepSeek V4 Pro через Timeweb AI API
5. Стриминг SSE, валидатор ответа (_validate_answer)
6. Провенанс: [src:SUBJECT/SLUG#SEG | раздел: заголовок] → ссылка в читалку
7. Блок «## Не найдено в материалах» обязателен в каждом ответе
8. max_tokens: short=8192, standard=12288, full=16384 (DeepSeek reasoning buffer)
9. Vision (OCR фото): Gemini 3.5 Flash

## Экраны

1. **Логин** — форма входа
2. **Дашборд** — список предметов, прогресс, быстрый вход в чат
3. **Предмет** — источники, загрузка (drag & drop), поиск, билеты
4. **Читалка** — оглавление + текст сегмента + картинки
5. **Чат** — стриминг, история, ввод текстом и фото
6. **Билеты** — список вопросов, генерация ответов, экспорт

## Правила

- Дизайн «Ночной атлас»: две темы (тёмная и светлая, по системным настройкам, переключатель в навбаре), токены в :root
- CSS inline, без внешних файлов
- Vanilla JS, без React/Vue
- Один файл `studylab.py` для бэкенда (FastAPI)
- Фронтенд inline в Python-файле (как mklib_web.py)
- Все данные на сервере, наружу ничего не отправляется кроме Timeweb AI API
- Эмбеддинги считаются локально (ollama), не через внешний API
